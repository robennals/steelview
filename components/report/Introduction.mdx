# Fact-report components

This library is the set of building blocks for a Steelview fact report: charts, maps, timelines, quotes and claim checks that all look and behave the same way. Use them to put a new report together quickly, and to make sure every figure in it can be checked by the reader.

Each component takes plain data (numbers, labels, dates, sources), not the site's content types, so the same component works with frontmatter, a calculation or a story fixture.

## Principles every component follows

- **Show the full range, not a chosen slice.** A chart covers everything the source publishes, so the reader sees the long run and not just the years that make a point.
- **Every figure has a source.** Each component ends with a source line that links to the quoted reference it rests on.
- **Every number can be checked.** Charts offer a Graph/Table switch, so the exact values sit one click away.
- **Never colour alone.** Series, statuses and categories are also told apart by labels, shapes or line styles, so they survive colour blindness and a black-and-white printout.
- **Neutral ordering.** Items appear in data order, date order or alphabetical order, never in an order that puts one side first. No position is styled as more important than another.
- **Works without JavaScript.** Components render their full default view on the server. Filters and toggles add to the page; they are never needed to read it.
- **Design tokens, not colours.** Styles use the site's ink, paper, rule and series tokens, so dark mode works with no extra effort.

## Putting a figure in a report

Wrap the content in `ReportFigure`, which supplies the heading, a one-sentence description, the source line and an optional "About this data" note. On a fact page, point each source at the numbered reference on that page, whose id is `#source-<fact>-<n>`:

```tsx
<ReportFigure
  title="Net migration, year ending June"
  description="Net migration rose from 2021 and has fallen since its 2023 peak."
  sources={[{ label: 'ONS', href: '#source-net-migration-2024-1', number: 1 }]}
  note="Estimates before June 2021 use a different method."
>
  {/* the chart, table or list */}
</ReportFigure>
```

Most components already wrap themselves in `ReportFigure`: pass them `title`, `description`, `sources` and `note` directly.
